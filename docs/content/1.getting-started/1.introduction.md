`@outloud/model` turns the plain objects an API returns into instances of your own classes. A model converts dates, creates related models, and adds getters and methods next to the data, and `toJSON()` turns it back into plain data.

## Features
- **Typed** - Instances, mapping and relationships are fully typed, or typed from a generated API type with [`Model.typed()`](/guide/typing)
- **Mapping** - [`fromJSON`, `fromArray`](/guide/mapping) and mappers for `transform` options, with `null` handled
- **Relationships** - [Related models](/guide/relationships) and arrays of them, custom collections included
- **Dates** - [`Date`, or Day.js](/guide/dates), from date and date-time strings
- **Custom columns** - [Decorators](/guide/decorators) that convert values both ways
- **Composition** - Shared columns and methods through [mixins](/guide/composition)
- **Vue & Nuxt** - Works in refs and stores, and [across the server render](/guide/vue-nuxt)
- **Small** - About 3 kB gzipped, without dependencies

## Quick Example

```ts
import { Model, column, relation } from '@outloud/model'

class Role extends Model {
  declare id: string
  declare name: string
}

class User extends Model {
  declare id: string
  declare firstName: string
  declare lastName: string

  @column.dateTime()
  declare createdAt: Date

  @relation(() => Role)
  declare role: Role | null

  get fullName() {
    return `${this.firstName} ${this.lastName}`
  }
}

const user = User.fromJSON({
  id: '1',
  firstName: 'Hello',
  lastName: 'World',
  createdAt: '2024-01-15T10:00:00.000Z',
  role: { id: '2', name: 'Admin' },
})

user.fullName // 'Hello World'
user.createdAt // Date
user.role // Role
user.toJSON() // plain data, createdAt as an ISO string
```
