:::code-group
```bash [pnpm]
pnpm add @outloud/model
```

```bash [npm]
npm install @outloud/model
```

```bash [yarn]
yarn add @outloud/model
```

```bash [bun]
bun add @outloud/model
```
:::

The package is ES modules only and needs Node.js 20 or later on the server.

## TypeScript

Models use TypeScript's decorators. Enable them in `tsconfig.json`:

```json [tsconfig.json]
{
  "compilerOptions": {
    "experimentalDecorators": true
  }
}
```

In a Nuxt project, set it in `typescript.tsConfig.compilerOptions` of `nuxt.config.ts` instead. See [Vue & Nuxt](/guide/vue-nuxt).
