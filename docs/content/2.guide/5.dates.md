title: Dates
description: Convert date and date-time strings to Date, or to another date type such as Day.js.
---

## Date and time

`@column.dateTime()` converts an ISO date and time string to `Date`, and back to an ISO string in `toJSON()`.

```ts
import { Model, column } from '@outloud/model'

class User extends Model {
  @column.dateTime()
  declare createdAt: Date
}

const user = User.fromJSON({
  createdAt: '2023-11-17T15:24:06.764Z'
})

user.createdAt // Date
user.toJSON().createdAt // '2023-11-17T15:24:06.764Z'
```

## Day.js and other date types

Both decorators can return another date type, such as Day.js, instead of `Date`.

### Configure

Configure it once, when the app starts:

```ts
import dayjs, { type Dayjs } from 'dayjs'
import { configure } from '@outloud/model'

configure({
  date: {
    deserialize: (value: Date) => dayjs(value),
    serialize: (value: Dayjs) => value.toDate()
  }
})
```

### Declare the type

```ts
import type { Dayjs } from 'dayjs'
import { Model, column } from '@outloud/model'

class User extends Model {
  @column.dateTime()
  declare createdAt: Dayjs
}

const user = User.fromJSON({
  createdAt: '2023-11-17T15:24:06.764Z'
})

user.createdAt // Dayjs
user.toJSON().createdAt // '2023-11-17T15:24:06.764Z'
```

## Date

`@column.date()` converts a `YYYY-MM-DD` string to `Date`, and back to `YYYY-MM-DD` in `toJSON()`.

```ts
import { Model, column } from '@outloud/model'

class User extends Model {
  @column.date()
  declare birthDate: Date
}

const user = User.fromJSON({
  birthDate: '1990-01-01'
})

user.birthDate // Date
user.toJSON().birthDate // '1990-01-01'
```

`column.date()` reads `YYYY-MM-DD` as midnight in local time, so the day is the same in every time zone.
