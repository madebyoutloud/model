---
title: Typing from data
description: Give models the properties of a generated API type with Model.typed().
---

When the API's types already exist, for example generated from an OpenAPI spec, `Model.typed<Data>()` gives the model's instances the properties of `Data`, instead of declaring each of them again.

```ts
import { Model } from '@outloud/model'
import type { components } from '~/api/schema'

type ProviderData = components['schemas']['Provider']

class Provider extends Model.typed<ProviderData>() {
  get label() {
    return `${this.name} (${this.id})`
  }
}

const provider = Provider.fromJSON(data)
provider.name // string, from ProviderData
```

It changes only types: `Model.typed()` returns `Model` itself, so the class behaves as any other model.

## Dates and relations

A property the model declares again must still fit `Data`. Generated types have dates as strings and relations as plain objects, so leave those out of `Data` with `Omit` and declare them on the model:

```ts
import { Model, column, relation } from '@outloud/model'

class Provider extends Model.typed<Omit<ProviderData, 'createdAt' | 'owner'>>() {
  @column.dateTime()
  declare createdAt: Date

  @relation(() => Owner)
  declare owner: Owner | null
}
```

A related model typed from its own data fits without `Omit`, as `Owner` here has every property of `OwnerData`:

```ts
class Owner extends Model.typed<OwnerData>() {}
```

## Base classes

TypeScript can't infer the class `typed()` is called on once `Data` is given. On a subclass of `Model`, pass the class as the second type argument:

```ts
class Project extends RestModel.typed<ProjectData, typeof RestModel>() {}
```

Or redeclare `typed` on the base class once, with `TypedMethod`, and leave it out everywhere else:

```ts
import { Model, type TypedMethod } from '@outloud/model'

abstract class RestModel extends Model {
  declare static typed: TypedMethod<typeof RestModel>

  static endpoint: string
  abstract id: string
}

class Project extends RestModel.typed<ProjectData>() {
  static override endpoint = 'v1/projects'
}
```
