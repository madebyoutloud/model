---
title: Models
description: Define a model, create it from data, update, serialize and clone it.
---

Every model extends `Model`. Declare the properties its data has with `declare`; plain properties need no decorator.

## Define model
Create a class that extends `Model` and declare its properties.

```ts
import { Model } from '@outloud/model'

class Post extends Model {
  static endpoint = 'v1/posts'

  declare id: string
  declare uid: string
  declare title: string

  get endpoint() {
    return `${Post.endpoint}/${this.id}`
  }

  get link() {
    return `/p/${this.uid}`
  }
}
```

## Create model
`create` takes typed values. For data from an API, use [`fromJSON`](/guide/mapping), which also accepts `null`.

```ts
const post = Post.create({
  id: '123',
  uid: 'my-post',
  title: 'My post'
})
```

Data for a property that only has a getter, such as `link` above, is skipped, so an API that adds a field with the same name doesn't break the model.

## Update model
`merge` updates the given values and keeps the others, for example with an API's response after saving. Or change a property directly.

```ts
post.merge({
  title: 'My post - updated'
})

// or
post.title = 'My post - updated'
```

## Serialize model
`toJSON` returns the model as plain data, with columns serialized. `JSON.stringify` calls it as well.

```ts
const json = post.toJSON()
```

## Clone model
`clone` returns a new instance with the same data, to change without affecting the original, for example in a form.

```ts
const post2 = post.clone()
```
